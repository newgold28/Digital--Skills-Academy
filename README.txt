===========================================
DIGITAL SKILLS TRAINING ACADEMY WEBSITE
===========================================

PROJECT DESCRIPTION:
This is a multi-page website for Digital Skills Training Academy, built using HTML5 and CSS3 only (no JavaScript).

FOLDER STRUCTURE:
academy-website/
│
├── index.html          - Home page with hero, welcome, and featured courses
├── about.html          - About page with academy info, mission, and vision
├── courses.html        - Courses page listing 5+ courses with descriptions
├── contact.html        - Contact page with form and social media links
├── README.txt          - This file
│
├── css/
│   └── style.css       - Main stylesheet with responsive design
│
└── images/             - (Note: Images are loaded from Pexels CDN)

PAGES INCLUDED:
1. Home Page (index.html)
   - Website logo
   - Navigation menu
   - Hero banner image (background)
   - Welcome message
   - Featured courses section (3 courses)
   - Footer

2. About Page (about.html)
   - Academy information
   - 2+ images
   - Mission statement
   - Vision statement
   - Core values
   - External resource links

3. Courses Page (courses.html)
   - 5+ courses listed
   - Each course has an image, title, and description
   - Categories: Development, Data Science, Marketing, Design, Security, Cloud Computing

4. Contact Page (contact.html)
   - Contact information (address, phone, email)
   - Contact form
   - Social media links (Facebook, Twitter, LinkedIn, Instagram, YouTube)
   - FAQ section

HTML FEATURES:
- Semantic HTML5 tags: <header>, <nav>, <main>, <section>, <article>, <footer>
- Navigation between all pages
- Links to 3+ external websites (W3Schools, MDN Web Docs, Coursera, Codecademy)
- 5+ images with appropriate alt attributes
- Different image sizes used throughout

CSS FEATURES:
- Custom color palette (blue and white theme)
- Background images and gradients
- Borders, shadows, and rounded corners
- Flexbox layout for navigation and components
- CSS Grid layout for courses and content sections
- Responsive design with media queries for:
  * Mobile devices (< 768px)
  * Tablets (768px - 1024px)
  * Desktop computers (> 1024px)
- Hover effects and transitions

EXTERNAL LINKS INCLUDED:

RESPONSIVE BREAKPOINTS:
- Mobile: max-width 480px
- Tablet: max-width 768px
- Desktop: max-width 1024px

HOW TO RUN:
1. Open index.html in any modern web browser
2. Navigate between pages using the nav menu
3. Or use a local server (npm run dev)

TECHNOLOGIES USED:
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Vite (for development server and build)
